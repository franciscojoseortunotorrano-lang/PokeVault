# PokeVault ⚡

**Autor:** Francisco José Ortuño Torrano  
**Tipo de Proyecto:** Aplicación Web de Gestión de Cartas y Mazos  

---

## 📝 Descripción

**PokeVault** es una plataforma web diseñada para coleccionistas y jugadores de cartas. Permite a los usuarios organizar su colección personal, consultar información detallada de sus cartas y construir mazos personalizados. Además, la plataforma cuenta con un panel de administración para la gestión global del catálogo de cartas y la publicación de noticias o novedades en el portal.

---

## ✨ Características Principales

### 👤 Para Usuarios
* **Gestión de Colección:** Registra e ingresa tu inventario personal de cartas para mantenerlo almacenado de forma segura.
* **Consulta e Inventario:** Explora y busca cartas dentro de tu colección o del catálogo general.
* **Creador de Mazos:** Agrupa e independiza tus cartas organizándolas en mazos personalizados.

### 🛡️ Para Administradores
* **Gestión de Catálogo (CRUD):** Añade, edita o elimina cartas del sistema global.
* **Portal de Noticias:** Publica, actualiza y gestiona anuncios o novedades visibles para todos los usuarios.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3
* **Backend:** PHP
* **Base de Datos:** MySQL
* **Servidor Web:** Apache

---

## 📋 Requisitos Previos

Antes de desplegar la aplicación, asegúrate de contar con:

1. Un servidor web compatible con las tecnologías del proyecto (ej. XAMPP, LAMP, Nginx).
2. Un gestor de base de datos configurado.
3. Navegador web moderno (Chrome, Firefox, Edge, Safari).

---

## 🚀 Instalación y Despliegue

Sigue estos pasos para poner el proyecto en marcha:

1. **Clonar o descargar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/pokevault.git
   ```
2. **Subir archivos al servidor:**
   Copia el contenido del proyecto a la carpeta raíz de tu servidor web (por ejemplo, `htdocs` en XAMPP o `/var/www/html/` en servidores Linux).

3. **Configurar la Base de Datos:**
   * Crea una base de datos en tu servidor.
   * Importa el archivo de script SQL de la base de datos.
   * Edita el archivo de configuración de conexión a la base de datos con tus credenciales local/servidor.

4. **Acceder a la Aplicación:**
   Abre tu navegador e ingresa a la URL correspondiente:
   `http://localhost/pokevault` o `http://tu-dominio.com`
